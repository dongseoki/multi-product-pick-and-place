# D03 요구사항 명세 — 인쇄면을 보호하는 로봇팔 병목 파지

> D03 · 요구사항 명세 · 작성 이동석(PM) · 검토 이동석(QA·운영) · 상태 작성 · v0.1 · 관련 T-01~T-06

## 요구사항 계층

| 계층 | 요구사항 |
| --- | --- |
| Stakeholder | 포장 담당자가 외관 검사 후 마지막 병을 2×2 박스에 담을 때 병의 인쇄면과 이미 담긴 병을 보호하고 싶다. |
| System | 서로 다른 시작 좌표 10개와  B라인에서 2x2박스의 위치 10개에 대해 각 1회 시험한다. 인쇄면 접촉, 낙하, 기존 병 접촉이 발생한 회차는 각각 0회이고, 목표 칸 안착은 9회 이상이어야 한다. |
| Subsystem | 파지는 주어진 병 좌표를 이용해 병목을 잡는다. 이송은 병을 바닥에 내려놓을 때까지 지지하며 기존 병과의 접촉을 피한다. 배치는 그리퍼가 병을 놓은 뒤 목표 칸 바닥의 지지와 칸 경계 안쪽에 머무르는지를 시뮬레이션 시간 1초 동안 확인한다. |

## 시험 장면과 범위

- 정차한 트레일러와 그 위의 2×2 박스를 고정한다. 세 칸에는 병이 있고 마지막 칸은 비어 있다. 목표 칸 좌표는 모든 회차에서 같다.
- 대상 병은 투입 구역에 직립해 있다. 사전에 정한 10개의 수평 시작 좌표를 사용하며, MuJoCo 초기화 단계에서 해당 회차의 좌표를 제어 코드에 전달한다.
- 범위 밖(Won’t)은 영상 인식과 빈 칸 탐색, 뚜껑 검사, 자동 재시도·실패 복구, 트레일러 이동, 실물 로봇 검증이다.

## 요구사항 표

| ID | 종류 | 요구사항 | 우선 | 근거 | 확인 |
| --- | --- | --- | --- | --- | --- |
| R-01 | 기능 | 10회 중 인쇄면 접촉이 발생한 회차는 0회다. 접근 시작부터 그리퍼가 물러날 때까지 로봇팔 또는 그리퍼의 충돌 형상이 대상 병 몸통에 한 번이라도 닿으면 접촉으로 기록한다. | Must | 포장 중 인쇄면 보호 | T-01 |
| R-02 | 기능 | 10회 중 낙하가 발생한 회차는 0회다. 들어 올린 병이 바닥에 지지되기 전에 그리퍼의 지지를 잃고 아래로 떨어지면 낙하다. 목표 칸 위에서 공중에 놓아 떨어뜨린 경우도 포함한다. | Must | 이송 중 병 이탈 방지 | T-02 |
| R-03 | 기능 | 10회 중 9회 이상 목표 칸에 안착한다. 병을 놓은 시점부터 시뮬레이션 시간 1초 동안 병이 자기 바닥면으로 목표 칸 바닥에 지지되고, 바닥면 전체가 칸 안에 머물러야 한다. | Must | 마지막 칸 적재 완료 | T-03 |
| R-04 | 안전 | 10회 중 기존 병 접촉이 발생한 회차는 0회다. 접근 시작부터 그리퍼가 물러날 때까지 로봇팔·그리퍼 또는 대상 병이 기존 세 병 중 하나라도 건드리면 별도 충돌 실패로 기록한다. | 안전 | 이미 적재한 병 보호 | T-04 |
| R-05 | 성능 | 자동 동작 시작부터 로봇이 대기 자세로 복귀할 때까지의 시뮬레이션 시간을 회차별로 측정하고 상한 이하인지 확인한다. 상한은 예비 시험 후 본시험 전에 초 단위로 확정한다. | Should | 회차별 소요 시간 비교 | T-05 |
| R-06 | 운영 | 박스 벽 접촉 여부를 회차별로 기록한다. 목표 칸 바닥에 병 바닥이 닿는 것은 정상 배치다. | Should | 배치 중 간섭 확인 | T-06 |

R-01~R-04를 모두 만족하면 전체 시험에 합격한다. 그리퍼가 병을 지지한 채 다른 위치에 내려놓으면 오배치로 기록한다. 접촉이나 낙하 없이 발생한 오배치는 10회 중 허용되는 안착 실패 1회로 집계할 수 있다. 사이클타임과 박스 벽 접촉은 별도로 기록한다.

## 판정 테스트 초안

| ID | 확인할 사례 |
| --- | --- |
| T-01 | 로봇팔 링크 또는 그리퍼가 대상 병 몸통에 한 번 닿으면 전체 시험에 실패한다. |
| T-02 | 이송 중 병이 빠지거나 공중에서 놓여 떨어지면 이후 안착하더라도 전체 시험에 실패한다. |
| T-03 | 접촉과 낙하가 없을 때 9회 안착은 통과하고 8회 안착은 실패한다. 1초 이내에 바닥 지지를 잃거나 바닥면이 칸을 벗어나면 그 회차는 안착 실패다. |
| T-04 | 로봇팔·그리퍼 또는 대상 병이 기존 병을 한 번 건드리면 전체 시험에 실패한다. |
| T-05 | 초 단위 상한과 같은 시간은 달성, 초과는 미달성으로 기록한다. |
| T-06 | 칸 바닥 지지와 박스 벽 접촉을 구분하고, 벽 접촉 여부를 기록한다. |
