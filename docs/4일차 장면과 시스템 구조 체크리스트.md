# 4일차 장면과 시스템 구조 체크리스트

[AGENTS.md](../AGENTS.md)의 외부 참고 자료에 있는 **팀프로젝트 4일차 장면과 시스템 구조.pdf**를 기준으로, 아래 순서대로 진행한다. 괄호 안의 숫자는 PDF 뷰어에서 표지를 1쪽으로 센 페이지 번호다. PDF의 로봇 A 예시는 문서 형식만 참고하고, 병 10개·3칸 선반·카메라 인식 등 예시 조건은 가져오지 않는다.

## 1. 장면을 만들기 전에 시험 조건 확정 (4쪽, 11–12쪽)

- [x] 장면 v0은 박스 위치를 고정해 기본 동작을 점검한다. 최종 시험은 병 시작 좌표와 B라인 컨베이어 벨트 위 박스 정지 위치를 사전에 짝지은 10쌍을 각 1회 시험한다. 박스는 회차 초기화 때만 옮긴다. [문제 정의서](problem.md)와 [요구사항 명세](requirements.md)에 반영했다. (4쪽, 11–12쪽)
- [x] 시연 범위는 마지막 병 1개의 병목 파지·이송·배치다. 병 시작 좌표와 목표 칸 좌표는 초기화에서 제어 코드로 전달하고, 영상 인식·빈 칸 탐색·벨트 구동·움직이는 박스 추적은 범위에 넣지 않는다. (11–12쪽)

## 2. D07 [장면 구성표](scene.md) 작성 (11–12쪽)

- [x] [팀 차터](charter_v2.md)의 로봇팔·그리퍼를 장면 구성표에 적었다. [제조사 모델 출처](scene-model-notes.md#모델-출처-후보)와 [병목 파지 검증 기준](scene-model-notes.md#단일-병-파지들기-시험)은 모델 검토 및 시험 기록에 정리했다. (11–12쪽)
- [x] 후보 모델을 MuJoCo에서 로드하고 관절 위치를 직접 설정해 팔과 손가락의 자세가 바뀌는 것을 확인했다. 재현 명령과 확인 범위는 [모델 검토 및 시험 기록](scene-model-notes.md#모델-로드-및-자세-변화-확인)에 적었다. (11–12쪽)
- [x] 팔·그리퍼 구동과 손가락 관절 연동을 구성하고, 단일 병 파지·들기 시험을 실행했다. 손가락의 뚜껑·어깨 접촉을 허용하는 기준으로 재시험해 [합격 결과를 기록했다](scene-model-notes.md#단일-병-파지들기-시험). 양쪽 손가락이 병목을 잡고 몸통에 닿지 않은 채 병을 들어 올렸다. (11–12쪽)
- [x] 단일 병 시험을 통과한 제조사 URDF와 MuJoCo 구동 구성을 장면 v0의 기반으로 정했다. v0의 대기 자세는 장면 배치에서 확정한다. (11–12쪽)
- [x] 대상 병 1개, 기존 병 3개, 마지막 칸이 빈 2×2 박스, 정지한 B라인 컨베이어 벨트, 투입 구역의 구성과 가정값을 적었다. 길이는 m, 질량은 kg로 표기하고, 고정 요소와 회차별 변경 값을 구분했다. (11–12쪽, 15쪽)
- [x] [v0 기준 배치](scene.md#v0-기준-배치)에 박스 위치, 투입 병 위치와 로봇 대기 자세를 기록했다. 투입 병목 접근과 빈 칸 하강·후퇴의 기하 검증 결과 및 관절각은 [접근 경로 검사](scene-model-notes.md#장면-v0-접근-경로-검사)에 정리했다. (11–12쪽)
- [x] 병목·보호 대상 몸통·병 바닥, 목표 칸 바닥·벽, 기존 병을 구분하는 [이름과 경계](scene-model-notes.md#병목접촉칸-경계)를 정리했다. XML 검증 기대값으로 병 4개, 질량 합 0.600 kg, 3칸 점유·1칸 비움을 적었다. 실제 XML 검증은 3단계에서 진행한다. (12쪽, 15쪽)

## 3. MuJoCo 장면 v0 생성 및 검증 (15–16쪽)

장면 v0는 MuJoCo에서 처음 만드는 기본 작업 장면이다. 로봇팔·그리퍼, 집을 병 1개, 기존 병 3개와 마지막 빈 칸이 있는 2×2 박스를 배치하고 박스는 정지한 B라인 컨베이어 벨트 위 한 위치에 고정한다. 먼저 뷰어에서 물체가 겹치지 않고 마지막 칸이 비어 있는지 확인한다. 제어 코드가 준비되면 같은 장면에서 병목을 잡아 빈 칸에 넣는 기본 동작을 점검한다. 박스 위치를 바꾸는 최종 10회 시험과는 별개다. (4쪽, 15–16쪽)

- [x] 구성표를 바탕으로 [장면 v0 MJCF](../scenes/v0.xml)를 만들었다. 제조사 로봇 파일은 준비 스크립트에서 생성하고, 장면 XML에는 작업물·고정물·대기 자세를 정의했다. (15쪽)
- [x] XML을 로드해 병 4개, 총질량 0.600 kg, 세 칸 점유와 마지막 빈 칸을 확인했다. [실행 명령과 실제 출력](scene.md#장면-v0-실행과-확인)을 저장했다. (15–16쪽)
- [x] MuJoCo 렌더링에서 병·박스·그리퍼의 배치와 빈 칸을 확인했다. 대기 상태로 1초 동안 진행해 의도한 바닥 지지 접촉만 발생했음을 확인하고 [장면 스크린샷](scene-v0.png)을 저장했다. (4쪽, 16쪽)

## 4. D06 [시스템 구조](architecture.md) 작성 (5–6쪽, 8쪽)

- [x] 모듈 관계도와 상태 기계를 작성했다. 초기화에서 병·목표 칸을 넘기고, 접근 → 파지 → 이송 → 배치 → 후퇴·대기 복귀를 지시하는 흐름과 관측 피드백을 표시했다. (5쪽, 8쪽)
- [x] 관계도의 연결 9개를 인터페이스 표에 옮겼다. 좌표·명령·관측 데이터의 형식, 좌표계·단위, 전달 시점을 적었다. (6쪽, 8쪽)
- [x] MuJoCo 관측에서 `TrialResult`를 만드는 기준을 적었다. 접촉·낙하·안착·사이클타임의 관측 조건을 정의했고, 시간 상한은 D03대로 예비 시험 이후로 남겼다. (5–6쪽, 8쪽)

## 5. D08 [안전 개념](architecture.md#d08-안전-개념) 작성 (7–8쪽)

- [x] PDF 7쪽의 ‘로봇 / 하면 안 되는 일 / 감지 / 막는 동작’ 표로 안전 개념을 작성했다. 실패 회차만 정지·기록하고, 초기화 후 다음 예정 회차로 진행한다. 같은 회차를 자동 재시도하거나 실패 상태에서 복구하지 않는다. (7–8쪽)
- [x] 인쇄면 접촉·낙하·기존 병 접촉을 R-01·R-02·R-04에 연결했다. 사이클타임(R-05)은 정지 제한시간과 구분하고, 박스 벽 접촉(R-06)만 발생하면 진단 로그에 남기고 계속 실행하도록 했다. (7–8쪽)
- [x] 제어 명령이 끊기면 이전 명령으로 계속 움직이지 않도록 워치독의 감지·회차 중단·로그 규칙을 정의했다. (7쪽)
