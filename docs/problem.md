# D01 v2 문제 정의서 — 인쇄면을 보호하는 로봇팔 병목 파지

> D01 · 문제 정의서 · 작성 이동석(PM) · 상태 초안 · v2

## 사용자(페르소나)

소량 생산 작업장의 포장 담당자. 외관 검사가 끝난 병을 투입 구역에서 받아 2×2 박스에 한 병씩 세워 담고, 네 칸이 모두 채워지면 적재를 마친다.

## 현재 작업 흐름(As-Is)

① 작업자가 빈 2×2 박스를 포장대의 지정된 구역 안에 놓는다\
→ ② 외관 검사가 끝난 병을 투입 구역에서 받는다\
→ ③ 몸통 인쇄면에 손이 닿지 않도록 병목을 잡는다\
→ ④ 병을 들어 박스의 빈 칸 위로 옮긴다\
→ ⑤ 병을 빈 칸에 수직으로 내려놓고 손을 뗀다\
→ ⑥ 네 칸이 모두 채워졌는지 확인하고 적재를 마친다

작업자는 병마다 ②~⑤를 반복한다. 이번 프로젝트에서 로봇은 마지막 병 한 개의 ③~⑤를 맡는다. 박스 준비, 병 투입, 앞선 세 병의 적재, 포장 완료 확인은 작업자가 맡는다.

## 현재 작업의 불편

외관 검사를 마친 뒤에도 포장 중 몸통 인쇄면에 자국이 남을 수 있다고 가정한다. 작업자는 병을 옮길 때 인쇄면에 손이 닿지 않도록 잡는 위치에 신경을 써야 한다. 현장 작업량, 작업 시간, 인쇄면 접촉 빈도는 측정 자료가 없어 수치를 생략한다.

## MuJoCo 시연과 측정

정차한 트레일러와 그 위의 2×2 박스를 고정한다. 세 칸에는 병이 있고 마지막 칸은 비어 있다. 투입 구역 안에서 직립 병의 시작 위치는 수평 좌표(`x`, `y`)만 바꾸고, MuJoCo 초기화 단계에서 시작 좌표를 로봇 제어 코드에 전달한다. 영상 인식은 시연 범위에서 제외한다.

| 측정 항목 | 기록 기준 |
| --- | --- |
| 인쇄면 접촉 | 접근부터 그리퍼가 물러날 때까지 로봇팔이나 그리퍼가 대상 병의 몸통에 닿았는지 기록한다. |
| 이송 중 낙하 | 병을 들어 올려 목표 칸에 내려놓기까지 낙하가 있었는지 기록한다. |
| 목표 칸 안착 | 병을 놓은 뒤 1초 동안 병이 자기 바닥면으로 칸 바닥에 지지되고 바닥면 전체가 칸 안에 머무르는지 확인한다. |
| 주변 접촉 | 로봇팔·그리퍼 또는 대상 병이 기존 병에 닿았는지 확인하고, 박스 벽 접촉도 따로 기록한다. |
| 사이클타임 | 자동 동작 시작부터 로봇이 대기 자세로 복귀할 때까지의 시간을 기록한다. |

투입 구역 안에서 사전에 정한 시작 좌표 10개를 기록하고 각 좌표에서 1회씩 시험한다. 10회 전체에서 인쇄면 접촉, 이송 중 낙하, 기존 병 접촉이 각각 0회이고 목표 칸 안착이 9회 이상이면 합격이다. 세부 판정 기준은 [D03 요구사항 명세](requirements.md)를 따른다.

## 왜 로봇인가

| 질문 | 답 |
| --- | --- |
| 물체를 옮기거나 다루는가? | 예. 병목을 잡아 병을 들어 올리고 2×2 박스의 마지막 빈 칸에 세워 넣는다. |
| 같은 동작을 반복하는가? | 예. 작업자는 병마다 잡기 → 옮기기 → 내려놓기를 반복한다. 시연에서는 마지막 병 한 개의 적재를 반복 시험한다. |
| 사람에게 불편하거나 위험한가? | 포장 작업은 사람이 전부 수동으로 하기 번거롭다. 작업자는 몸통 인쇄면에 손이 닿지 않도록 잡는 위치에 신경을 써야 한다고 가정한다. |
| 앱·센서·고정 장치로 해결할 수 있는가? | X. 이송에는 물리적으로 병을 움직이는 장치가 필요하다.  |
