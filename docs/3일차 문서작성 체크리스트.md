# 3일차 문서작성 체크리스트

## 성공 조건 합의

- [x] 인쇄면 무접촉, 이송 중 무낙하, 마지막 칸 안착을 Must 세 가지로 둔다.
- [x] 사전에 정한 10개 시작 좌표에서 각 1회 시험한다. 10회 전체에서 인쇄면 접촉 0회, 이송 중 낙하 0회, 목표 칸 안착 9회 이상이어야 합격이다.
- [x] 대상 병의 몸통 전체를 인쇄면 보호 영역으로 둔다. 접근 시작부터 병을 놓고 그리퍼가 물러날 때까지 로봇팔 또는 그리퍼의 충돌 형상(geom)이 보호 영역에 한 번이라도 닿으면 해당 회차를 접촉으로 기록한다.
- [x] 그리퍼가 병을 놓은 뒤 관측 시간 동안 병이 자기 바닥면으로 목표 칸 바닥에 지지되고, 바닥면 전체가 칸 경계 안에 머무르면 안착으로 판정한다. 기울기 허용각은 두지 않는다.
- [x] 안착은 그리퍼가 병을 놓은 시점부터 MuJoCo 시뮬레이션 시간으로 1초 동안 관측한다.
- [x] 병을 들어 올린 뒤 안정적으로 내려놓기 전에 그리퍼의 지지를 잃고 아래로 떨어지면 낙하로 기록한다. 칸 위에서 병을 공중에 놓아 떨어뜨린 경우도 포함한다. 그리퍼가 병을 지지한 채 다른 위치에 내려놓으면 오배치로 기록한다.
- [x] 로봇팔·그리퍼 또는 이송 중인 병이 이미 놓인 병에 닿으면 별도 충돌 실패로 기록한다. 10회 시험에서 허용 횟수는 0회다. 박스 벽 접촉은 기록한다.
- [x] 사이클타임은 Should로 두고 자동 동작 시작부터 대기 자세 복귀까지 측정한다. Must 합격과 시간 목표 달성 여부는 각각 기록한다.
- [x] 트레일러는 정차 상태로 고정하고 2×2 박스는 트레일러 위의 지정된 자세에 고정한다. 세 칸은 병으로 채우고 마지막 목표 칸을 비워 둔다. 병 투입 좌표만 바뀌며 초기화 단계에서 제어 코드에 전달한다.
