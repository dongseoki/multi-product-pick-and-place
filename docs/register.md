이동석이 네 역할을 겸하며, 검토자 칸의 괄호는 해당 문서를 검토할 때 맡는 역할을 나타낸다. 검토자 지정은 검토 완료를 뜻하지 않는다.

상태는 미작성 → 작성 → 검토 → 승인 순서로 갱신한다. 관련 요구사항의 ‘—’는 식별자가 미정임을 뜻한다. D03에서 요구사항 ID를 부여하면 관련 산출물에 해당 ID를 기록하고, D04에서 대응하는 테스트 ID를 연결한다.
