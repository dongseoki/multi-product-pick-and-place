# 병목 파지 모델 검토 및 시험 기록

길이는 m, 질량은 kg를 기본 단위로 사용한다.

## 모델 출처 후보

- [Elephant Robotics ROS 2 저장소](https://github.com/elephantrobotics/mycobot_ros2)는 myCobot 280 M5와 Adaptive Gripper 조합을 URDF 모델 목록에 제공한다. 이 조합을 우선 검토하되, MuJoCo에 올려 관절과 충돌 형상을 검증하기 전에는 채택을 확정하지 않는다.

### 모델 로드 및 자세 변화 확인

제조사 [URDF 커밋](https://github.com/elephantrobotics/mycobot_ros2/blob/25bec49559ba119395f4d335d3da230bdad494d8/mycobot_description/urdf/mycobot_280_m5/mycobot_280_m5_adaptive_gripper.urdf)을 고정해 검사한다. 스크립트는 임시 디렉터리에서 DAE 메시를 원본 단위에 맞춰 m 단위 OBJ로 변환한다. 변환 도구는 이 명령에서만 사용하며, 프로젝트의 기본 의존성에는 추가하지 않는다.

```bash
uv run --locked --with trimesh==5.2.2 --with pycollada==0.9.3 \
  python scripts/check_mycobot_model.py
```

MuJoCo 3.3.7에서 팔 관절 6개, 그리퍼 관절 6개, 메시 15개가 로드됐다. 관절 위치(`qpos`)를 직접 설정했을 때 팔과 손가락의 자세가 변하는 것을 확인했다. 가져온 모델에는 액추에이터와 관절 연동 제약이 모두 없어서, 이 검사에서는 URDF의 연동 관계를 읽어 종속 관절 위치를 직접 설정한다.

### 단일 병 파지·들기 시험

```bash
uv run --locked --with trimesh==5.2.2 --with pycollada==0.9.3 \
  python scripts/check_neck_grasp.py
```

동작을 눈으로 확인하려면 위 명령 끝에 `--viewer`를 붙인다. MuJoCo 창이 열리고 같은 시험을 1/4 속도로 반복 재생한다. 접촉점 표시가 켜져 있으며, 병목은 초록색, 뚜껑은 빨간색, 어깨는 주황색, 몸통은 파란색이다. 재생은 판정 결과를 바꾸지 않으며, 창을 닫으면 종료된다.

- **설정:** 위치 액추에이터 7개(팔 6개, 그리퍼 1개)와 URDF 기반 손가락 관절 연동 제약 5개를 추가했다. 병은 지름 24 mm·높이 20 mm의 병목을 가진 150 g 자유 물체로 두고, 어깨는 몸통에서 병목으로 좁아지는 원뿔대로 모델링했다. 병에는 구속이나 직접 위치 제어를 적용하지 않는다. 이 시험은 로봇의 이상적인 중력 보상을 가정하며, 로봇 자체 충돌·실기 토크 검증과 박스·벨트 배치는 범위 밖이다.
- **합격 기준:** 양쪽 손가락의 병목 접촉으로 병을 들어 올린다. 손가락의 뚜껑·어깨 접촉은 허용하되 별도로 기록하며, 이를 병목 지지로 세지 않는다. 로봇팔·그리퍼의 몸통 접촉은 허용하지 않는다. 마지막 0.5초 동안 양쪽 손가락이 병목에 닿은 채 받침 접촉 없이 병을 20 mm 이상 들어 올려야 한다.
- **실행 결과 — 합격:** 최대 29.52 mm, 유지 구간 최저 29.12 mm. 양쪽 손가락 병목 접촉 500/500 스텝, 받침 접촉 0/500 스텝. 손가락의 뚜껑·어깨 접촉은 기록됐고, 몸통을 포함한 금지 접촉은 없었다.
- **범위:** 이 결과는 단일 병을 들기 위한 시험이다. 컨베이어와 박스가 있는 장면은 [장면 v0 접근 경로 검사](#장면-v0-접근-경로-검사)에서 다룬다.

## 병목·접촉·칸 경계

- 병 바닥을 기준으로 몸통은 높이 0~0.110, 어깨는 0.110~0.120, 파지용 병목은 0.120~0.140, 뚜껑은 0.140~0.150에 둔다. 병목 파지 가능 높이의 가정값은 0.020이다.
- 병마다 `*_body`(인쇄면 보호 대상), `*_shoulder`, `*_neck`, `*_cap`으로 충돌 형상을 구분한다. 병 바닥면은 몸통 원통의 아랫면으로 정의한다. 바닥 지지는 칸 바닥과의 접촉 위치·방향으로 벽 접촉과 구분할 수 있어야 한다.
- 박스 좌표계의 양쪽 축을 따라 칸을 배치한다. 안쪽 경계 기준으로 `(+x, +y)` 칸을 목표로 비워 두고 나머지 세 칸에 병을 한 개씩 둔다. `target_cell_floor`와 외벽·칸막이를 구분해 이름을 붙인다.

## 장면 v0 접근 경로 검사

[v0 기준 배치](scene.md#v0-기준-배치)의 대기 자세에서 시작했다. 표의 각도는 베이스에서 손목 방향으로 나열했으며 단위는 rad다.

| 경로 기준점 | 1축 | 2축 | 3축 | 4축 | 5축 | 6축 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 투입 병목 파지 위치 | 1.50377918 | -0.34368283 | 2.29565762 | 1.06771958 | -1.63832048 | -3.01996943 |
| 빈 칸 바닥까지 내린 위치 | 2.85640203 | -0.36399169 | 2.25191576 | 1.13177073 | -1.63832071 | -3.01996985 |

```bash
uv run --locked python scripts/check_v0_layout.py
```

대기 자세에서 45 mm 수직 하강한 뒤 닫기 → 60 mm 상승 → 로봇 베이스 주위로 약 77.50° 회전 → 빈 칸 바닥까지 수직 하강 → 열기 → 수직 후퇴 순으로 확인했다. 회전각은 빈 칸 중심을 기준으로 계산했다. 실제 장면 v0에서 **674개 자세**를 검사했고, 바닥·투입대·박스 벽·컨베이어·기존 병 및 대상 병 몸통과의 금지 접촉이 없었다. 손가락의 병목·뚜껑·어깨 접촉과 의도한 바닥 지지는 허용했다.

이 검사는 이송 구간의 병을 경로상에 직립시킨 **기하 검사**다. 자세 사이의 연속 충돌, 로봇 자체 충돌, 실제 제어에 따른 미끄러짐·낙하·안착은 검증하지 않았다.
